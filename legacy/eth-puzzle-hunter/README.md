## 💡 How It Works

1. **Find Contracts** - Search Etherscan for "puzzle"
2. **Check Balance** - Verify has ETH to win
3. **Analyze Code** - Understand the challenge
4. **Solve Puzzle** - Find password/answer/solution
5. **Claim Prize** - Call solve() function
6. **Receive ETH** - Prize sent to your wallet!
