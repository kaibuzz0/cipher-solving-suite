# 📚 Cryptography 101

## Introduction

Cryptography is the practice of securing communication through mathematical techniques.

## Basic Concepts

### Hash Functions
- Convert input to fixed-size output
- One-way (irreversible)
- Examples: MD5, SHA-256, SHA-3

### Symmetric Encryption
- Same key for encryption/decryption
- Fast but key distribution is hard
- Examples: AES, ChaCha20

### Asymmetric Encryption
- Public key + Private key
- Slower but solves key distribution
- Examples: RSA, ECC

## For the Challenge
