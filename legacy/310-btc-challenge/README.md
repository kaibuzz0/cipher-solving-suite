## 🧩 Puzzle Categories

### 1. Cryptographic Puzzles
- **RSA Factorization** - Break large semiprimes
- **ECC Discrete Log** - Elliptic curve challenges
- **AES Key Derivation** - Brute force resistant keys
- **Hash Collisions** - Find matching hashes
- **Quantum-Resistant** - Post-quantum cryptography

### 2. Steganography
- **Image Puzzles** - Hidden data in pixels
- **Audio Secrets** - Spectrogram messages
- **Text Concealment** - Zero-width characters
- **PDF Mysteries** - Hidden layers
- **Video Frames** - Frame-by-frame analysis

### 3. Mathematical Challenges
- **Prime Hunting** - Find special primes
- **Diophantine Equations** - Integer solutions
- **Modular Arithmetic** - Chinese Remainder Theorem
- **Lattice Problems** - Closest vector problems
- **Combinatorial** - NP-hard challenges

### 4. Programming Challenges
- **Reverse Engineering** - Analyze compiled binaries
- **Smart Contracts** - Solidity puzzles
- **Zero-Knowledge Proofs** - ZK-SNARK challenges
- **Malware Analysis** - Safe reverse engineering
- **Blockchain Exploits** - Test your skills
