## 🔍 Specific Research Tasks

### Task 1: Clue Archive Review (20 min)
```
In Discord:
- Search unsolved clue numbers
- Read entire thread history
- Note attempted solutions
- Look for pattern hints
- Check if anyone close to solving

Document findings in notepad
```

### Task 2: Image Analysis (25 min)
```
If clue has image:
1. Open stegonline.georgeom.net
2. Upload image
3. Check ALL bitplanes (24 total)
4. Try LSB extraction
5. Check metadata
6. Look for QR codes
7. Try different color channels

Document what you find
```

### Task 3: Cipher Decoding (20 min)
```
If clue has encrypted text:
1. Copy to dcode.fr
2. Try auto-detection first
3. Manual attempts:
   - Caesar (try all 26 shifts)
   - ROT13
   - Base64
   - Hex
   - Vigenere (if have key hint)
4. Look for patterns

Save successful decodes
```

### Task 4: Coordinate Research (15 min)
```
If clue has coordinates:
1. Go to Google Maps
2. Enter coordinates
3. Check Street View
4. Look for:
   - Landmarks
   - Statues
   - Public art
   - Businesses
   - Access points
5. Check satellite view too

Document location details
```
