# GitHub Command Site Integration

This repository is a connected spoke for `kaibuzz0/Git-hub-command-site`.

## Contract

The source repository remains authoritative. The command site receives only a bounded public metadata snapshot generated by:

```bash
python scripts/build_site_data.py
python scripts/build_agent_ops.py
python scripts/export_command_site_snapshot.py
```

The Pages build publishes the result at:

`https://kaibuzz0.github.io/cipher-solving-suite/data/repo-snapshot.json`

The central hub can fetch that URL, validate `repo.id == cipher-solving-suite`, aggregate it with other repository snapshots, and render it through the generic multi-repository UI.

## Exported surfaces

- repository identity and source commit
- dashboard status/stats
- canonical shared tools
- discovered/registered toolsets
- structured active cases
- opportunity catalog
- intelligence feed
- source-health registry state
- Agent Operations snapshot
- bounded recent commit activity
- stable GitHub/Pages/Actions links

The snapshot does **not** export arbitrary file bodies, credentials, secrets, private data, or unbounded research artifacts.

## Agent rule

Normal repository work should continue to update canonical repo data and manifests. Do not hand-edit the command-site snapshot. The exporter regenerates it from repository truth during the Pages build. If a new canonical collection should become visible in the central hub, extend the exporter and hub schema/rendering deliberately rather than creating a parallel data source.
