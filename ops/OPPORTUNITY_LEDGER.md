# Verified Opportunity Ledger

Use this as the human-readable index of currently actionable opportunities. Detailed research can live in issues or dated notes, but only verified/current items belong here.

## Status legend
- `ACTIVE`: verified and currently actionable.
- `WATCH`: legitimate source, but no currently verified target or deadline.
- `EXPIRED`: verified historical opportunity that is no longer actionable.
- `UNVERIFIED`: lead only; do not spend significant time or interact with a target until checked.

## Required fields for new entries

| Field | Requirement |
|---|---|
| Name | Exact official program/challenge name |
| Status | ACTIVE / WATCH / EXPIRED / UNVERIFIED |
| Category | CTF / puzzle / hackathon / bug bounty / audit / government challenge / other |
| Official source | First-party page whenever possible |
| Verified | YYYY-MM-DD |
| Deadline/cadence | Exact date/time or recurring cadence |
| Entry cost | Include currency; say free when verified |
| Prize/payout | Current stated amount/range, not historical maximum |
| Eligibility | Geography, age, account, team, skill, KYC, etc. |
| Scope/rules | Required for security/bug-bounty work |
| Fit score | 1-5 based on skill match, expected effort, and payout realism |
| Next action | One concrete safe/legal step |

## Daily research policy

The daily agent pass should prioritize opportunities that are:
1. currently open,
2. free or low-cost to enter,
3. clearly authorized,
4. compatible with the suite's existing skills,
5. measurable by deadline, prize, and submission rules.

Never count an old prize pool, marketing headline, or simulated scanner result as current availability.
