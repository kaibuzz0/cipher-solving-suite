# VS Code workspace UI

The public Pages UI is intentionally designed as a compact dark workspace rather than a marketing dashboard.

Design goals:

- VS Code-inspired title bar, activity rail, explorer tree, editor tab, breadcrumbs, and status bar.
- Dark theme with high information density and readable contrast.
- Folder-first navigation for Opportunities, News/Intel, Cases, Tools, Evidence, Collection Health, Sources, Prompts, and Agent Workflow.
- Current-view search and contextual filters.
- Mobile explorer drawer while preserving the desktop workspace model.
- No change to canonical repository data contracts; the site remains a read-oriented view over generated repo state.
