HANDOFF PROTOCOL

Agent Workflow

  1. Orient. Start with README.md, then read AGENTS.md, the latest handoff, and work queue.
  2. Check assigned sources. Use python scripts/source_registry.py list --due --agent <agent> to find stale/never-checked intelligence lanes.
  3. Research. Preserve source URLs, timestamps, scope, uncertainty, and useful evidence.
  4. Publish intelligence. Put sourced user-facing updates in data/intelligence.json using the intelligence workflow.
  5. Deduplicate. Intelligence items use deterministic fingerprints based on normalized title + source URL.
  6. Build. Keep source, generated artifacts and evidence separated.
  7. Verify. Tests first; deterministic replay or compile checks second.
  8. Publish state. Update structured case/tool/catalog data so users can see the result.
  9. Handoff. Record exact changes, failures, evidence and one next action.
Authorization boundary: intelligence about a target or bounty is not authorization to test it. Only test security targets covered by explicit CTF, audit, lab, or bug-bounty authorization and scope.
