HANDOFF PROTOCOL

Agent Workflow

  1. Orient. Start with README.md, then read AGENTS.md, the latest handoff, and work queue.
  2. Claim. Choose the smallest unclaimed, verifiable task.
  3. Research. Save sources, timestamps, hashes, assumptions and authorization scope.
  4. Build. Keep source, generated artifacts and evidence separated.
  5. Verify. Tests first; deterministic replay or compile checks second.
  6. Navigate. Update README quick links if major paths/tools/workflows changed.
  7. Handoff. Record exact changes, failures, evidence and one next action.
Authorization boundary: only test security targets covered by explicit CTF, audit, lab, or bug-bounty authorization and scope.
