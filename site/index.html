HANDOFF PROTOCOL

Agent Workflow

  1. Orient. Start with README.md, AGENTS.md, handoff, and work queue.
  2. Check assigned sources. Use python scripts/source_registry.py list --due --agent <agent>.
  3. Record source state. Use python scripts/source_check_history.py record ... after a real review.
  4. Research. Preserve URLs, timestamps, scope, uncertainty, hashes, and evidence.
  5. Publish intelligence. Promote only reviewed useful discoveries to the canonical feed.
  6. Inventory evidence. Hash/classify artifacts before moving legacy files.
  7. Verify. Tests and deterministic checks before handoff.
  8. Handoff. Record exact changes, failures, evidence, and next action.
Authorization boundary: intelligence about a target or bounty is not authorization to test it.
